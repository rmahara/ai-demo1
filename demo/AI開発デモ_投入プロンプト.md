# Claude Code投入用プロンプト集（3ターミナル並列版）

※デモ本番中に、事前準備した3分割ターミナルの各画面にコピー＆ペーストして実行するためのプロンプトリストです。
※各プロンプトは互いに競合（ファイルのコンフリクト）が発生しないように対象領域（レイヤー）が分割されています。

---

## ターミナル1（左）：[Task A] ドメイン層の改善（ValueObject化）
**狙い**: 業務ルールのカプセル化。バックエンドの深い理解と高度なリファクタリング能力を見せる。

```text
OrdersControllerやViewModelを確認し、「製造数量（Quantity）」の画面での扱いをValueObject化して改善してください。
現在は画面では整数のPrimitive型で扱われていますが、これを専用のValueObject（例えば `ConcreteQuantity` などのクラス名）に変更し、Viewに反映させてください。
今回はデモ（時間制限あり）のため、変更にあたっては以下を厳守してください。
- 小数点以下2桁で扱うことをValueObject内にカプセル化する
- 既存のすべてのView（一覧画面の表示フォーマット、入力フォームの `input type="number"` の `step` 属性、バリデーション表示など）において、小数点以下2桁（例: 1.25㎥）のルールが目で見て一目で変わるように修正する
- **※重要※ DB（Entity Framework Core構成、DbContext、マイグレーション等）や実際の永続化処理の変更は一切行わないでください。ViewModelとView層の修正のみにとどめてください。**
```

---

## ターミナル2（右上）：[Task B] UIのモダナイズ（ダークモード化）
**狙い**: 全画面への影響。フロントエンド（CSS/JS）の全体的な書き換え能力を見せる。

```text
このWebアプリケーション全体（メニュー画面やダッシュボード等を含むすべての画面）に「ダークモード」を追加してください。
以下の要件を満たすように実装してください。
- 画面の右上に太陽/月のアイコンを使ったトグルスイッチを配置し、ユーザーが手動でライト/ダークを切り替えられるようにする
- ユーザーの選択状態をLocalStorage等に保存し、次回アクセス時やページ遷移時にも維持されるようにする
- Bootstrap 5の組み込みダークモード機能（data-bs-theme）をうまく活用し、既存のレイアウトやChart.jsのグラフが見づらくならないように調整する
```

---

## ターミナル3（右下）：[Task C] 外部API連携機能の追加
**狙い**: 特定画面へのコンポーネント追加。ゼロからのAPI通信実装能力を見せる。

```text
ダッシュボード（Index画面等）の空いているスペースに、「今日・明日の天気情報」を表示するコンポーネントを新規に追加してください。
以下の要件を満たすように実装してください。
- 外部APIとして「Open-Meteo（https://api.open-meteo.com/v1/forecast）」を利用する（APIキー不要のため）
- JavaScriptのfetch等を用いて非同期でデータを取得し、画面ロード後にポンと表示させる
- 表示内容は、現在地の天気アイコン（またはテキスト）、今日の最高/最低気温、明日の天気予報など、パッと見でわかりやすい親切なデザインにする
- バックエンドのModelsや既存のDB構造は一切変更しないこと
```
