## 1. テスト方針

### 1.1 テスト対象

| 対象層 | テスト内容 |
|--------|-----------|
| Service 層 | ビジネスロジック（全メソッド） |
| Controller 層 | アクションの正常系・異常系 |
| バリデーション | ViewModel の入力チェック |
| ユーティリティ | 採番ロジック、計算ロジック |

### 1.2 テストフレームワーク

- **xUnit**: テストランナー
- **Moq**: リポジトリ・依存サービスのモック化
- **FluentAssertions**: アサーション（可読性向上）

### 1.3 カバレッジ目標

| 対象 | 目標カバレッジ |
|------|---------------|
| Service 層 | 80%以上 |
| Controller 層 | 70%以上 |
| 全体 | 70%以上 |

### 1.4 命名規則

```
メソッド名: {テスト対象}_{条件}_{期待結果}
例: CreateAsync_ValidInput_ReturnsNewOrderId
    CreateAsync_MissingCustomerId_ThrowsValidationException
```

## 2. OrderService 単体テスト

### 2.1 CreateAsync

| テストID | テスト名 | 入力条件 | 期待結果 |
|---------|---------|---------|---------|
| UT-OS-001 | 正常系：正常な受注データで登録成功 | 全項目有効値 | 新規 OrderId (>0) が返る |
| UT-OS-002 | 正常系：電話受注で登録 | OrderType=0 | Status=Received で登録 |
| UT-OS-003 | 正常系：事前発注で登録 | OrderType=1 | Status=Received で登録 |
| UT-OS-004 | 異常系：存在しない得意先ID | CustomerId=9999 | EntityNotFoundException |
| UT-OS-005 | 異常系：存在しない配合ID | MixId=9999 | EntityNotFoundException |
| UT-OS-006 | 異常系：数量ゼロ | Quantity=0 | BusinessRuleException |
| UT-OS-007 | 異常系：数量マイナス | Quantity=-1 | BusinessRuleException |
| UT-OS-008 | 境界値：数量最小値 | Quantity=0.1 | 正常登録 |
| UT-OS-009 | 境界値：数量最大値 | Quantity=999.9 | 正常登録 |
| UT-OS-010 | 境界値：数量最大値超 | Quantity=1000.0 | BusinessRuleException |
| UT-OS-011 | 異常系：納入日時が受注日より前 | DeliveryDate < 受注日 | BusinessRuleException |

#### テストコード例（UT-OS-001）

```csharp
[Fact]
public async Task CreateAsync_ValidInput_ReturnsNewOrderId()
{
    // Arrange
    var mockRepo = new Mock<IOrderRepository>();
    mockRepo.Setup(r => r.AddAsync(It.IsAny<Order>())).ReturnsAsync(1);

    var mockCustomerRepo = new Mock<ICustomerRepository>();
    mockCustomerRepo.Setup(r => r.FindByIdAsync(1)).ReturnsAsync(new Customer { CustomerId = 1 });

    var mockMixRepo = new Mock<IMixRepository>();
    mockMixRepo.Setup(r => r.FindByIdAsync(1)).ReturnsAsync(new Mix { MixId = 1 });

    var service = new OrderService(mockRepo.Object, mockCustomerRepo.Object, mockMixRepo.Object);

    var viewModel = new OrderCreateViewModel
    {
        CustomerId = 1,
        MixId = 1,
        Quantity = 10.0m,
        OrderType = OrderType.Phone,
        DeliveryDate = DateTime.Now.AddDays(1)
    };

    // Act
    var result = await service.CreateAsync(viewModel);

    // Assert
    result.Should().BeGreaterThan(0);
    mockRepo.Verify(r => r.AddAsync(It.IsAny<Order>()), Times.Once);
}
```

#### テストコード例（UT-OC-001）

```csharp
[Fact]
public async Task Create_ValidInput_RedirectsToIndex()
{
    // Arrange
    var mockService = new Mock<IOrderService>();
    mockService.Setup(s => s.CreateAsync(It.IsAny<OrderCreateViewModel>()))
               .ReturnsAsync(1);

    var controller = new OrdersController(mockService.Object);
    var viewModel = new OrderCreateViewModel { /* 有効なデータ */ };

    // Act
    var result = await controller.Create(viewModel);

    // Assert
    var redirect = result.Should().BeOfType<RedirectToActionResult>().Subject;
    redirect.ActionName.Should().Be("Index");
}
```
