# 基本設計書

**プロジェクト名**: 生コンAI出荷管理システム
**バージョン**: 1.0 ドラフト
**作成日**: 2026年3月9日
**対象フェーズ**: ウォーターフォール — 基本設計

---

## 1. システム概要

### 1.1 目的

生コンクリート工場における受注〜出荷業務を一元管理するWebアプリケーションを構築する。
電話受注・事前発注の複合フローに対応し、配車計画・出荷指示・請求処理を支援する。

### 1.2 システム範囲

| 区分 | 内容 |
|------|------|
| 対象業務 | 受注入力、配車計画、出荷指示、請求処理、マスタ管理 |
| 対象ユーザー | 工場オペレーター、管理者 |
| 除外範囲 | 外部EDI連携、モバイルアプリ |

## 2. アーキテクチャ設計

### 2.1 技術スタック

| レイヤー | 採用技術 |
|----------|----------|
| フレームワーク | ASP.NET Core 10 MVC |
| データベース | SQLite（EF Core 9） |
| UI | Bootstrap 5 + Chart.js |
| 認証 | ASP.NET Core Identity |
| レポート出力 | ClosedXML.Report（Excel） |
| テスト | xUnit + Moq |

```

│           クライアント（ブラウザ）         │

└──────────────┬──────────────────────────┘
               │ HTTP/HTTPS
┌──────────────▼──────────────────────────┐
│        ASP.NET Core 10 MVC              │
│  ┌──────────┐  ┌────────┐  ┌─────────┐ │
│  │Controllers│  │Services│  │  Repos  │ │
│  └──────────┘  └────────┘  └────┬────┘ │

└─────────────────────────────────┼───────┘
                                  │ EF Core
```

### 2.3 MVCレイヤー責務

| レイヤー | 責務 |
|----------|------|
| Controller | リクエスト受付、バリデーション呼び出し、View返却 |
| Service | ビジネスロジック（配車ロジック、請求計算等） |
| Repository | EF Core を介したDB操作 |
| Model / ViewModel | エンティティ定義、画面入出力データ |

## 5. 認証・認可設計

### 5.1 ロール定義

| ロール | 権限範囲 |
|--------|---------|
| Admin | 全機能 + ユーザー管理 |
| Operator | 受注・出荷・請求の参照・入力（マスタ管理は参照のみ） |
| ReadOnly | 全画面参照のみ |

### 5.2 認証方式

- ASP.NET Core Identity によるフォーム認証
- セッションタイムアウト: 60分
- パスワードポリシー: 8文字以上、英数字混在
